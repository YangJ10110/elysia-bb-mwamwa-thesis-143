# Elysia BB Thesis

This repository contains the code and documentation for the Elysia BB Thesis project.

## Setup

To set up the project, you need to activate the `thesis_env` virtual environment.

### Activating the Virtual Environment

1. Open a terminal or command prompt.
2. Navigate to the project directory:
    ```sh
    cd /C:/Users/Jerome Yang/OneDrive - Mapúa University/Documents/TERA/elysia-bb-thesis
    ```
3. Activate the virtual environment:
    - On Windows:
        ```sh
        .\thesis_env\Scripts\activate
        ```
    - On macOS and Linux:
        ```sh
        source thesis_env/bin/activate
        ```

Once the virtual environment is activated, you can install the required dependencies and run the project.

### Installing Dependencies

To install the required dependencies, run:
```sh
pip install -r requirements.txt
```
